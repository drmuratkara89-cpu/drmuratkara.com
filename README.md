# drmuratkara.com

Statik, mobil uyumlu Dr. Murat Kara web sitesi. GitHub Pages ile yayınlanmak üzere hazırlanmıştır.

## Yayın
- Özel alan adı: `drmuratkara.com`
- `CNAME` dosyası hazırdır.
- `sitemap.xml`, `robots.txt`, yapılandırılmış veriler ve temel sosyal paylaşım metadataları dahildir.
- GitHub Pages yayına alındıktan sonra Turhost DNS kayıtları GitHub Pages hedeflerine yönlendirilmelidir.

## Not
Gizlilik ve aydınlatma metinleri hukuk/KVKK kontrolü tamamlanana kadar `noindex` tutulmuştur.


## Yayın varlıkları
- `favicon.svg`: tarayıcı simgesi
- `og-dr-murat-kara.jpg`: sosyal paylaşım görseli (1200×630)
